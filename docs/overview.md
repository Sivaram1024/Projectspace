# Placement & Skill Gap Analytics Platform

## Overview

A college placement management platform that empowers students with personalized readiness insights while giving placement administrators powerful tools to manage the entire placement lifecycle.

**The Problem**: Students lack visibility into their placement readiness and skill gaps relative to actual job requirements. Placement cells struggle with manual eligibility tracking and have no data-driven insights into student preparedness trends.

**The Solution**: A dual-portal system where students see transparent readiness scores, actionable skill recommendations, and real-time eligibility status — while admins manage drives, define criteria, and analyze placement trends through comprehensive dashboards.

## Roles

### Student
- View personalized Placement Readiness Score (0-100) with transparent calculation breakdown
- Manage profile: department, year, CGPA, skills with proficiency levels (beginner/intermediate/advanced)
- Browse upcoming placement drives with automatic eligibility determination
- Receive skill gap analysis comparing current skills against job requirements
- Get notified about new opportunities, eligibility changes, and deadlines

### Placement Admin
- Create and manage placement drives with company details, roles, and requirements
- Define eligibility criteria (CGPA thresholds, department restrictions, year requirements)
- View complete student directory with readiness metrics and skill profiles
- Access analytics dashboard showing placement trends, skill distributions, eligibility rates
- Broadcast notifications to targeted student groups

## Key Scenarios

1. **Student checks readiness**: Opens dashboard, sees 78/100 score, reviews breakdown showing strong technical skills but gap in communication — clicks through to recommendations

2. **Student browses drives**: Filters to eligible drives only, sees "TechCorp - Software Engineer" with green checkmark, reviews required skills and applies

3. **Admin creates drive**: Enters company details, selects required skills with minimum proficiency, sets CGPA cutoff of 7.0, publishes to eligible students

4. **Admin reviews trends**: Opens analytics, sees 40% of students lack cloud computing skills despite high demand — plans workshop

## Design Direction

**Aesthetic**: Professional, data-forward, trustworthy — a career platform that takes students seriously. Clean dashboard layouts with prominent data visualizations and clear information hierarchy.

**Color Palette**:
- Deep navy (#1e293b) — primary, authority, professionalism
- Teal accents (#14b8a6) — positive states, eligibility, progress
- Warm amber (#f59e0b) — warnings, skill gaps, attention needed
- Crisp white/slate backgrounds for content areas

**Typography**: Modern geometric sans-serif with bold metrics and readable body text. Clear visual hierarchy distinguishing scores, labels, and descriptions.

**Key Visual Elements**:
- Circular progress gauge for readiness score
- Skill cards with horizontal proficiency bars
- Timeline/card view for upcoming drives
- Comparison charts for skill gap visualization
- Status badges for eligibility states
